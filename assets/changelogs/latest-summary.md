🎉 Welcome to Imify v2.3.2!

This feature update brings **Password-Protected PDF Support** to PDF Studio, introduces a rich **Text Layer & Typography Engine** with editable Photoshop (PSD) export in Image Filling, adds **Advanced Image Captioning** in Image Splicing, and unifies **Pan & Zoom Canvas Navigation** across all creative tools.

✨ Major Highlights (v2.3):

- 📄 **PDF Studio Suite**: 2-way PDF conversion with new password-protected PDF unlocking, high-DPI rasterization, and ZIP archiving.
- ✍️ **Text Layers & Typography**: Full text layer editing with native editable PSD export, gradient fills, shadows, and snap guides in Image Filling.
- 💬 **Splicing Caption System**: Inside/outside caption placement with 9-point visual picker, formula offsets, and container opacity.
- 🔍 **Unified Canvas Viewport**: Smooth pan/zoom navigation, 65% screen height viewport, and touch-optimized selection priority.
- 🖼️ **Quick Collage Maker**: Intuitive 3-stage workspace to compose multi-image photo collages with customizable layouts and drag-to-swap.
- 🛠️ **Emergency Recovery Mode**: Dedicated `/recovery` page to diagnose cache anomalies and restore app access safely.
- ⚡ **Smart Automated Concurrency & Fallbacks**: Intelligent hardware detection, instant workspace restoration, and URL auto-sync.
