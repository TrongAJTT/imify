### How to Report Bugs

If you encounter any issues, bugs, or unexpected behavior while using Imify, we would love to hear from you so we can fix it!

To report a bug effectively, follow these recommended steps:

#### 1. Export System Logs (Recommended)

Providing system diagnostic logs helps us investigate the exact state of your application and speeds up debugging significantly:

1. Enable **Developer Mode** from the **About** dialog (view guide **Enable Developer Mode**).
2. Open the **Developer Tools** dialog (click the code icon in the header).
3. Go to the **System Monitor** tab.
4. Click the **Export System Log** button. This will download a sanitized diagnostic JSON file (`imify-debug-*.json`) containing your application configuration and preferences.

#### 2. Open an Issue on GitHub

Once you have the log file ready:

1. Visit our official repository: [GitHub Issues](https://github.com/trongajtt/imify/issues).
2. Click **New Issue** and describe the problem you experienced.
3. Attach the downloaded diagnostic JSON log file to the issue description.
4. Describe the steps required to reproduce the bug, along with any error messages you observed.

> [!NOTE]
> To be effective, you can profile screenshots (or screen recordings) of the bug and attach them to the issue.
> You may optionally include hardware specs, OS info, and browser version via the environment log.

> [!IMPORTANT]
> Before submitting, please double-check to make sure you don't include any **personally identifiable information (PII)** or other sensitive information in the issue.

Thank you for helping us make Imify better!
