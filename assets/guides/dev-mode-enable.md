### Enable Developer Mode

To enable Developer Mode in Imify and access advanced developer tools, follow these steps:

1. Go to the "About" dialog.
2. Keep clicking on the **Imify** logo or the **Version** badge in the top-left corner until Developer Mode is enabled.
